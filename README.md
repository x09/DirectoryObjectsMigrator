# Directory Objects Migrator v1.0

Инструмент для миграции объектов Active Directory из Microsoft AD в Samba AD.

## Возможности

- Миграция пользователей, групп, организационных подразделений (OU), контактов
- Сохранение иерархии подразделений
- Перенос атрибутов объектов (кроме системных и паролей)
- Обработка ссылочных атрибутов (member, manager, managedBy)
- Идемпотентность: повторные запуски безопасны
- Инкрементальная миграция с tracking через SQLite
- Отложенное (DEFERRED) членство в группах для объектов вне области миграции
- Графический интерфейс на PyQt5
- Детальное логирование и отчеты

## Требования

### Системные пакеты (ALT Linux)
```bash
apt-get install python3-module-ldap3 python3-module-PyQt5 python3-modules-sqlite3
```

### Python версия
- Python 3.10+

## Архитектура

### Поэтапная миграция

1. **Анализ (Discovery)**: Сканирование source домена, классификация объектов
2. **Создание OU**: Создание иерархии организационных подразделений
3. **Создание объектов**: Users, Groups, Contacts (без ссылочных атрибутов)
4. **Перенос атрибутов**: Заполнение обычных атрибутов
5. **Ссылочные атрибуты**: Обработка member, manager, managedBy с DEFERRED tracking
6. **Верификация**: Проверка результатов миграции

## Особенности реализации

### Пароли пользователей
- Устанавливается случайный пароль (12 символов: a-zA-Z0-9_-), есть возможность задать фиксированный
- Все пользователи создаются в disabled состоянии

### UPN и Email
- Автоматическая замена domain суффикса: user@source.alt → user@dest.alt

### Идентификация объектов
- SQLite база данных для tracking миграции
- Маппинг по objectGUID (source ↔ destination)
- Обработка конфликтов: существующие объекты НЕ перезаписываются

### Членство в группах
- Члены внутри области миграции: добавляются сразу
- Члены вне области: помечаются DEFERRED, добавляются при повторных запусках

### Игнорируемые объекты
- Компьютеры (objectClass=computer)
- Служебные и дефолтные группы и пользователи (определябтся по SID)
- Builtin контейнеры
- ForeignSecurityPrincipals
- GPO объекты
- Exchange-специфичные атрибуты


### Workflow

1. Настроить подключения к Source и Destination DC
2. Указать Base DN для миграции (например: OU=Level2,OU=Level1,DC=source,DC=alt)
3. **Analyze**: Проанализировать объекты в source
4. **Preview**: Просмотреть план миграции (что будет создано/существует/конфликтует)
5. **Start Migration**: Запустить миграцию
6. **Report**: Сгенерировать отчет (опционально)

### Повторные запуски

Инструмент идемпотентен:
- Существующие объекты пропускаются
- DEFERRED ссылки разрешаются при доступности целевых объектов
- Группы обновляются новыми членами

## Ограничения v1.0

- ❌ Миграция паролей (технически невозможно через LDAP)
- ❌ DNS зоны
- ❌ Sites и Subnets
- ❌ GPO (Group Policy Objects)
- ❌ Компьютеры (требуют domain rejoin)

## Безопасность

- Пароли НЕ хранятся в конфигурационных файлах
- Существующие объекты в destination НЕ перезаписываются
- Детальное логирование всех операций
- Preview перед миграцией
- Dry-run режим

## Логирование

Логи сохраняются в `~/.config/DirectoryObjectMigrator/logs/migration_YYYYMMDD_HHMMSS.log`

Уровни:
- INFO: Информационные сообщения
- SUCCESS: Успешные операции
- WARNING: Предупреждения (EXISTS, DEFERRED)
- ERROR: Ошибки
- CONFLICT: Конфликты объектов

## Отчеты

HTML отчеты с детализацией:
- Статистика по типам объектов
- Список созданных/существующих/конфликтующих объектов
- DEFERRED ссылки
- Ошибки и предупреждения
