Directory Object Migrator — инструмент для миграции объектов Active Directory из Microsoft AD в Samba AD.

### Возможности

- ✅ Миграция подразделений (OU)
- ✅ Миграция пользователей
- ✅ Миграция групп с членством
- ✅ Миграция контактов
- ✅ Сохранение иерархии подразделений
- ✅ Трансформация атрибутов (UPN, email)
- ✅ Отложенное членство в группах (DEFERRED)
- ✅ Идемпотентные повторные запуски
- ✅ Режим симуляции (Dry Run)
- ✅ Детальное логирование
- ✅ Генерация отчетов (HTML/TXT)

### Ограничения

- ❌ Пароли пользователей НЕ мигрируются (устанавливаются случайные)
- ❌ DNS зоны не мигрируются
- ❌ GPO не мигрируются
- ❌ Компьютеры не мигрируются
